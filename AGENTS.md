## Git Branch Naming

Branch names **must** be descriptive and task-related. Never use auto-generated or random strings (e.g. `claude/nice-pare-55ef84`).

Use the format `type/short-description`:
- `feat/public-trip-submission`
- `fix/trip-log-date-parsing`
- `improve/seo-metadata`
- `chore/remove-stale-branches`
